**PolloPOS** es una aplicación móvil diseñada específicamente para optimizar y modernizar los procesos de venta, el manejo de pedidos y el control exhaustivo de caja en establecimientos de comida rápida y restaurantes. Con un enfoque principal en la usabilidad y la eficiencia operativa, la interfaz permite a cajeros y administradores ejecutar transacciones rápidas y seguras.

## 🛠️ Entorno y Tecnologías Utilizadas

- **Framework principal:** Android SDK nativo.
- **Lenguaje:** Java 11
- **IDE:** Android Studio (Gradle build system)
- **UI / UX:** Vistas desarrolladas en XML respetando los lineamientos de **Material Design**, integrando tipografías modernas, esquemas de color personalizados e iconos vectoriales de alta definición.
- **Control de Versiones:** Git / GitHub
